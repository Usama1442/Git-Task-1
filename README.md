## Basic Task 1: Create & Commit

* Initialize a new Git repository
* Create a file `hello.txt`
* Add some content to the file
* Stage and commit the file with a message
* Verify the commit using `git log`

---

##  Basic Task 2: Branching

* Create a new branch named `Task-2`
* Modify `hello.txt` by adding a new line
* Commit the changes in this branch
* Switch back to the `master` branch
* Verify that changes are not in `master`

---

## Advanced Task: Merge and Revert

* Merge the `Task-2` branch into `master`
* Check commit history to identify the latest commit
* Revert the last commit on `master`
* Verify that the changes from the merged branch are undone
* Confirm the history reflects the revert action
